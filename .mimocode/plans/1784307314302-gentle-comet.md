# Wire contact form to DB + Telegram

## What's happening now
- `ContactForm.tsx` POSTs to `/` as `application/x-www-form-urlencoded` — no backend handles it
- `book-call/route.ts` is the only API route (Neon DB + Telegram alerts)
- The contact form fields: name, email, company, budget, service, timeline, message

## Plan

### 1. Create `app/api/contact/route.ts`
Follow the exact same pattern as `book-call/route.ts`:

- **Table schema:** `contacts` table with `id`, `name`, `email`, `company`, `budget`, `service`, `timeline`, `message`, `created_at`
- **Validation:** require `name` and `email`
- **DB insert:** raw SQL via `@neondatabase/serverless` `neon()`
- **Telegram alert:** send formatted HTML message to same chat IDs
- **Response:** `{ success: true }` or error

### 2. Update `components/contact/ContactForm.tsx`
- Change fetch target from `"/"` to `"/api/contact"`
- Change Content-Type from `application/x-www-form-urlencoded` to `application/json`
- Send JSON body: `{ name, email, company, budget, service, timeline, message }`
- Remove `form-name` and `subject` hidden fields (not needed)
- Keep honeypot check (add server-side validation too)
- Remove `action="/?submitted=true"` and `method="POST"` attributes (JS handles submission)

### Files to modify
- **New:** `app/api/contact/route.ts`
- **Edit:** `components/contact/ContactForm.tsx`

## Verification

2. Fill out the contact form and submit

4. Check Telegram for notification

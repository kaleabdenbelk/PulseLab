# GA4 Integration Plan

## Goal
Add Google Analytics 4 (gtag.js) tracking to the Next.js App Router project.

## Approach
Add the GA4 snippet to `app/layout.tsx` using Next.js `<Script>` component with `strategy="afterInteractive"`. This ensures the tag loads after the page becomes interactive, avoiding impact on initial page load performance.

## Files to modify

### 1. `app/layout.tsx`
- Import `Script` from `next/script`
- Add two `<Script>` tags inside `<head>` (or at top of `<body>`):
  1. `src="https://www.googletagmanager.com/gtag/js?id=G-6CJM24M03J"` with `strategy="afterInteractive"`
  2. Inline script initializing `dataLayer`, `gtag()`, and `gtag('config', 'G-6CJM24M03J')`

## Implementation detail

```tsx
import Script from "next/script";

// Inside <html>, before <body>:
<Script
  src="https://www.googletagmanager.com/gtag/js?id=G-6CJM24M03J"
  strategy="afterInteractive"
/>
<Script id="google-analytics" strategy="afterInteractive">
  {`
    window.dataLayer = window.dataLayer || [];
    function gtag(){dataLayer.push(arguments);}
    gtag('js', new Date());
    gtag('config', 'G-6CJM24M03J');
  `}
</Script>
```

## Verification
1. Run `pnpm dev` and open the site
2. Check browser DevTools > Network tab — confirm `googletagmanager.com/gtag/js` loads
3. Check DevTools > Console — confirm no errors related to gtag
4. Visit Google Analytics > Realtime report — confirm the visit appears

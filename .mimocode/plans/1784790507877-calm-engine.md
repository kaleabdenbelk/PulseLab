# Image Optimization Plan

## Problem

Images load slowly because:
- `next.config.ts` is empty — no image optimization configured
- All `<Image>` components use `unoptimized` — bypasses Next.js optimization entirely
- 13 files use native `<img>` instead of Next.js `<Image>` — no WebP/AVIF conversion, no responsive sizing, no lazy loading
- No `priority` prop on above-the-fold images (hero)
- No `sizes` attribute — browser downloads full-resolution for all viewports
- Many `<img>` tags missing `width`/`height` — causes layout shift (CLS)
- External images from `allgoodstudio.com` not whitelisted in config

## Changes

### 1. `next.config.ts` — Add image optimization config

```ts
import type { NextConfig } from "next";

const nextConfig: NextConfig = {
  images: {
    formats: ["image/avif", "image/webp"],
    remotePatterns: [
      { protocol: "https", hostname: "allgoodstudio.com" },
    ],
  },
};

export default nextConfig;
```

This enables AVIF/WebP conversion and allows external images from `allgoodstudio.com`.

### 2. `components/projects/ProjectCard.tsx` — Remove `unoptimized`, add `sizes`

- Remove `unoptimized` from both `<Image>` usages
- Add `sizes` prop for responsive serving
- Keep `width`/`height` as-is (they're correct)

```tsx
// Line 28-34: Seal icon — keep unoptimized (tiny SVG, no benefit)
// Line 78-84: Project image — remove unoptimized, add sizes
<Image
  src={project.image}
  width={1672}
  height={941}
  sizes="(max-width: 768px) 100vw, 50vw"
  alt={`${project.name} — case study preview`}
/>
```
